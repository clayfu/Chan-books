## 本站宗旨
「禪屋」的宗旨是想藉此現代網路平臺，讓全球有緣的華人智者瞭解：頓教禪法是一門真正有智慧的修行者必須親證親悟的、不可思議的「形而上的心靈科學」。因為《大方等大集經》說:「如來能覺如是法界，是故名佛。」《大乘入楞伽經》說:「諸佛所證我亦同證。」以及法禪師父所說:「在這絕對體性中，精神與物質是一體的，...從絕對的體性上來看世出世間的一切，那都只是從一個體性上隨緣顯現的一種現象及作用罷了。所以，當一個行者大徹大悟的同時，自我的身心也同時消融於整個體、相、用之中，也就是說，這時候只有體、相、用，而沒有你、我、他。」而這只有現代的智者，才會相信、自證這個宇宙生命本源的法界--也就是今日科學家所發現的量子世界背後的世界。

## 站主著作

### 《禪  不可思議的形而上學的心靈科學 —— 一生成佛之道》(繁體、簡體、英文、雙語版)

本書所要傳達給讀者最重要的訊息是法禪法師所說:「見性成佛是學佛最基本，最重要、也是最終的要求。」「參禪只要有個想見性的念就夠了。」(成佛之道)「吾人修行之目的，無非是想了脫生死。」「人出生就註定要死亡，人的一生有什麼意義呢？不應只是混口飯吃而已，應該有更高的企求才對。...更高的企求就是去解決生死問題。」
而想要解決生死問題的關鍵，則在於個人的般若智慧。也就是他(她)要能了解、相信，眼前有生死輪迴的宇宙生命只是個有如夢境的幻相。也就是佛陀在《摩訶般若波羅蜜經》所說：「善男子！佛說諸法如幻如夢。若有眾生如實知，...則能知佛所說諸法實相***。」以及《大法炬陀羅尼經》所說：「佛言：『梵天！一切眾生長夜大睡，是中一人能覺悟已，即知眾生一切皆睡大睡深睡。我今既得如是覺已，云何當令一切眾生除斷睡眠、同得斯覺？梵天，是為第一以覺義故稱為佛陀。』」
所以，一個有般若智慧的人，只要時時有個想覺醒(見性)的念，就能跟佛陀一樣的從生命的大夢中醒過來了;就能達到《大般涅槃經》所說:「佛者名覺，既自覺悟，復能覺他。...以是覺故，不生、不老、不病、不死，是故名佛。」如此他(她)不就是「一生成佛、解脫生死」」了嗎?禪修或參禪其實就是如此的簡單。
所以，並不是生死不能解決，而是你(妳)是否願意了解、相信與覺醒?《太虛大師全書》:「一切有情都有成佛的可能性，故一切眾生皆是未來佛。」但願你(妳)也能開始了解與相信! 一念之間而已;尤其是自己已跨越了N世的奇妙因緣或業緣!!
*** 「諸法實相」指的就是量子世界背後的世界
